OpenStreetMap notes are reports anyone can leave on the OpenStreetMap map – a path that no longer exists, a missing shelter, a wrong name – for mappers to look into and fix. Freemap shows the open notes, so you can read them and pass them on to an editor. It needs an internet connection.

## Showing the notes

Turn on the :FaStickyNote: **OSM notes** overlay: it is in the menu under :FaEllipsisV: at the end of the map toolbar, its keyboard shortcut is <kbd>Shift</kbd>+<kbd>N</kbd>, and you can also type its name in the search box (see [Maps](#show=manual/maps)). The notes appear as pins from zoom 10 on.

## Reading a note

Click a pin to select the note. Its panel opens on the right, or over the lower half of a phone's screen, with its comments – what was written, by whom and when, and whether the note was closed or reopened. Links in a comment open in a new tab; a link to an OpenStreetMap element is followed by **show on map**, which finds the element and selects it in Freemap.

At the top of the panel, :FaEllipsisV: **Actions** holds the actions for the place, as in the map's context menu, and :FaExternalLinkAlt: **Open in…** beside it holds:

- **OpenStreetMap** opens the note's page, where you can comment on it or close it once it is fixed (you need an OpenStreetMap account),
- **JOSM** loads the note into the editor's notes layer,
- **iD** opens the note in the editor on openstreetmap.org.

The panel's × (or <kbd>Esc</kbd>) deselects the note, and so does turning the overlay off. A selected note is part of the link to the map, so whoever opens it sees the same note.

Freemap can't add notes or comment on them; that is done on openstreetmap.org. How to fix what a note reports yourself is described in [About Freemap and OpenStreetMap](#show=manual/about).
